# InfoMapper

A data-modeling tool for data warehouse work: logical entities, physical source tables and the mappings between them, on one canvas.

## Repository layout

| Folder | What's in it |
| --- | --- |
| `docs/` | Briefs and reference material |
| `docs/prototype/` | The clickable model workspace prototype, the reference for canvas behaviour |
| `spikes/` | Throwaway experiments that answer one question each. Nothing in here is merged into the application as is |
| `spikes/canvas-react-flow/` | AD-24: can React Flow carry the modeling canvas? Results in its `REPORT.md` |

The application itself is not started yet.
